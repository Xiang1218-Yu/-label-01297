# 下班倒计时小程序

这是一个帮助打工人计算下班倒计时以及实时估算今日薪资的微信小程序。界面设计简洁美观，提供直观的视觉反馈。

## How to Run

1.  **环境准备**：请确保已安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2.  **导入项目**：打开微信开发者工具，选择“导入项目”，目录选择本项目的根目录。
3.  **配置 AppID**：可以使用测试号 (Test ID) 或您自己的小程序 AppID。
4.  **运行**：点击工具栏的“编译”按钮，即可在模拟器中看到效果。

## Services

本项目为纯前端小程序，核心逻辑均在首页 `pages/index/index.js` 中实现：

*   **时间与倒计时**：`getTodayDateWithTime` 将“时:分”转为当日 Date；`formatDuration` 将秒数格式化为 HH:mm:ss；`updateState` 每秒根据当前时间与上下班时间计算是否加班、剩余/加班时长。
*   **薪资计算**：在 `updateState` 内根据日薪与工作时长算出每秒薪资率，按已工作时长累加“今日已赚”，超过下班时间后按加班秒数累加“亏了工资”。
*   **输入与状态**：日薪、上下班时间通过 `bindSalaryInput` / `bindStartTimeChange` / `bindEndTimeChange` 与选择器写入 data；开始/停止倒计时由 `startTimer`、`goBack`、`stopTimer` 控制。

## 测试账号

本项目为纯前端工具类小程序，不涉及后端登录系统，因此**不需要**特定的测试账号。用户打开小程序即可直接使用所有功能。

## 题目内容

我现在要开发一个 下班倒计时的微信小程序 ， 用户打开首页， 会有几个常用的下班时间按钮， 还有一个用户定义义的下班时间选择器和一个日工资金额。 用户可以点下班时间按钮， 或者输入自定义的下班时间后， 开始倒计时，每秒倒计时跳动就会增加当前的日工资金额，金额增加要有一个动画。 超过了下班时间没下班，在日工资下面额外显示名叫亏了工资一个负数的金额， 每秒跳动就增加这个亏工资金额。

**主要功能**：
1.  **首页交互**：包含常用下班时间快捷按钮、自定义时间选择器、日工资金额输入框。
2.  **核心逻辑**：
    *   用户设置下班时间后，开始倒计时。
    *   **工资动画**：每秒倒计时跳动，当前日工资金额随之增加，且包含数字跳动动画。
    *   **加班逻辑**：若超过下班时间，在日工资下方显示“亏了工资”及负数金额，且该负数每秒增加。
3.  **UI/UX 要求**：
    *   视觉分层（背景、阴影、边框）。
    *   布局规范（Flex/Grid，统一间距）。
    *   交互反馈（Hover、Loading、Toast）。
    *   风格统一。
